      How Direct Beam Works

      1. Direct Peer-to-Peer: Files stream directly from your browser's memory to the receiver via WebRTC DataChannels. Nothing is uploaded to cloud servers.

      2. 256 KB Adaptive Chunking: Files are sliced into 256 KB memory buffers, streamed sequentially with backpressure flow control to avoid freezing.

      3. DTLS Encryption: DataChannels use Datagram Transport Layer Security (DTLS) natively, ensuring complete cryptographic encryption in flight.

      Security & Privacy Protocol

      • Zero intermediary storage: Render hosts the signaling handshake only.

      • DTLS end-to-end encryption prevents packet interception or inspection.

      • Ephemeral rooms: All signaling session keys expire immediately when the host tab closes.
