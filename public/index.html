      How Direct Beam Works

      1. Direct Peer-to-Peer Pipeline

      Files are never stored on any cloud database or server disk. Senders stream binary buffers directly to receiver browser memory via WebRTC DataChannels.

      2. 256 KB Adaptive Chunking

      Incoming files are chunked into 256 KB frames. When backpressure ceiling is reached (8 MB), transfer yields to avoid page freezing.

      3. End-to-End Cryptography

      All packets are secured via native DTLS 1.3 protocol. Ephemeral session tokens expire as soon as the session closes.

      Security & Privacy Protocol

      Zero Cloud Intermediary: Cloudflare Workers edge hosts the signaling handshake only. File payloads never traverse our servers.

      Hardware-Grade DTLS: End-to-end cryptographic encryption prevents man-in-the-middle packet inspection.

      Ephemeral Session Keys: All cryptographic keys and temporary codes expire immediately upon disconnect.
